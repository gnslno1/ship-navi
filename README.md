# 배 흐름 나침반

배낚시할 때 **내가 바라보는 방향 기준으로** 배가 흘러가는 방향과 속도를 보여주는 웹앱(PWA)입니다.
앱스토어 설치 없이 휴대폰 브라우저로 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있고, 한 번 열면 바다에서 데이터가 끊겨도 동작합니다.

## 원리

- **배의 흐름**: GPS 위치를 최근 N초(기본 60초) 동안 모아 직선을 맞춰(가중 최소제곱) 속도 벡터를 구합니다. 순간 속도보다 GPS 튐에 훨씬 강합니다.
- **내가 보는 방향**: 휴대폰 나침반(방위 센서). 눕혀 들면 위쪽 모서리, 세워 들면 카메라가 향하는 방향을 "정면"으로 봅니다.
- 화면의 **12시 = 내 정면**. 노란 화살표가 배가 밀려가는 방향, 화살표 주변의 옅은 부채꼴이 오차 범위입니다.
- 바다 쪽을 보고 서 있다고 가정하고 채비 상태 힌트를 보여줍니다 (예: 배가 내 앞쪽으로 밀리면 채비가 배 밑으로 들어가기 쉬움).

## 휴대폰에서 쓰려면

앱 주소: https://gnslno1.github.io/ship-navi/ (GitHub Pages, `main` 브랜치에 push하면 1~2분 뒤 반영)

GPS·나침반은 보안 주소(HTTPS)에서만 동작합니다. 위 주소를 휴대폰에서 열고:
- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가". 시작 시 "동작 및 방향" 권한 허용.
- **Android (Chrome)**: 메뉴 → "앱 설치" 또는 "홈 화면에 추가". 위치 권한 허용.

PC에서 화면만 확인하려면 이 폴더에서 `python -m http.server 8765` 후 `http://localhost:8765/?demo=1` (가상 GPS 데모).

## 사용 팁

- 시작 후 **30초~1분**은 기다려야 값이 안정됩니다. 상단 "신뢰도" 칩을 보세요.
- 측정 구간: 조류가 자주 바뀌면 20초, 값이 출렁이면 60~90초.
- **나침반 보정이 중요합니다.** 배의 철판·엔진 때문에 휴대폰 나침반이 수십 도 틀어질 수 있습니다.
  포인트로 이동하면서 배가 2노트 이상으로 직진할 때, 휴대폰을 뱃머리 쪽으로 향하고
  설정 → "뱃머리 방향으로 자동 보정"을 누르면 GPS 진행 방향에 맞춰 보정됩니다. 서 있는 자리에서 하는 게 가장 정확합니다.
- 나침반이 이상하면 휴대폰으로 8자를 그리며 센서를 보정하세요.
- 화면 꺼짐 방지가 켜지지만 배터리를 많이 씁니다. 보조배터리 권장.

## "나침반 없음"이 뜰 때

- 상단의 나침반 칩을 누르면 설정 화면 아래 **센서 진단**에 원인과 해결 방법이 나옵니다.
- 안드로이드 Chrome: 주소창 왼쪽 아이콘 → 권한(사이트 설정) → **동작 센서** 허용 후 새로고침.
- 아이폰: 설정 → Safari → **동작 및 방향 접근** 허용 후 새로고침.
- "나침반 보정 필요"는 회전만 감지되고 북쪽을 모르는 상태입니다. 배가 직진할 때 "뱃머리 방향으로 자동 보정"을 누르면 쓸 수 있습니다.

## 한계

- GPS가 보는 것은 **배가 땅(지구) 기준으로 움직이는 것**(조류 + 바람)입니다. 물속 깊은 층의 조류와는 다를 수 있습니다.
- 0.2노트 이하로 아주 느리면 GPS 오차 때문에 방향이 부정확합니다 ("거의 정지"로 표시).
