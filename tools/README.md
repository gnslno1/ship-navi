# 도구

파이썬 3만 있으면 됩니다. `simulate_drift.py`는 numpy가 필요합니다 (`pip install numpy`).

## 워치 기록 분석 — `analyze_watch_log.py`

워치 시험 앱의 CSV 기록을 넣으면 같은 폴더에 HTML 보고서를 만듭니다 (브라우저로 열기).

```bash
python tools/analyze_watch_log.py log_20261023_190000.csv
```

보고서 내용:
- **요약**: GPS 정확도·끊김, 배터리 시간당 소모와 예상 사용 시간, 자기장 간섭 비율, 흐름 신뢰도 비율
- **그래프**: 흐름 속도, 방위(흐름·내 정면), GPS 정확도·위성, 자기장(정상 범위 띠), 기울기, 배터리, 이동 궤적
- **정지 시험**: 30분쯤 워치를 한자리에 둔 기록이면 자동으로 GPS 노이즈를 재서,
  앱의 신뢰도 기준(`FLOOR_K`)이 그 기기에 맞는지 알려줍니다. 자동 판단이 안 되면 `--stationary`를 붙이세요.

기록 파일 가져오는 방법은 [watch/README.md](../watch/README.md)를 보세요.

## 정확도 시뮬레이션 — `simulate_drift.py`

```bash
python tools/simulate_drift.py
```

실제 GPS처럼 오차가 수십 초 동안 한쪽으로 쏠리는 가짜 궤적을 수천 번 만들어 흐름 계산의 정확도를 잽니다.

### 결과 (2026-10-23)

GPS 오차 모형: 좋음(쏠림 1.5m) · 보통(3m) · 나쁨(5m). 방향 오차는 10번 중 9번이 들어가는 범위입니다.

**보통 GPS에서 속도·측정 구간별 방향 오차**

| 흐름 | 20초 | 40초 | 60초 | 90초 |
|---|---|---|---|---|
| 0.3kn | 97° | 59° | 42° | 31° |
| 0.5kn | 52° | 31° | 24° | 17° |
| 0.8kn | 30° | 19° | 15° | 11° |
| 1.2kn | 20° | 13° | 10° | 7° |

- 측정 구간이 길수록 정확합니다. 기본값을 **40초 → 60초**로 바꿨습니다.
- 0.3kn 이하의 느린 흐름은 1분 넘게 재도 방향이 크게 틀릴 수 있습니다.

**신뢰도 판정 수정**

이전 계산은 오차가 매초 따로 생긴다고 가정해서, 실제 오차보다 3~7배 작게 잡았습니다.
그래서 보통 GPS에서 "높음"으로 판정한 경우도 방향이 32°까지 틀렸습니다.
GPS 정확도(±m)에 비례하는 바닥값(`FLOOR_K = 0.0171`, `FLOOR_P = 0.66`)을 오차에 더하도록 고쳤습니다.

| 판정 | 이전 (보통 GPS, 60초) | 수정 후 | 목표 |
|---|---|---|---|
| 높음 | 30° | 10° | 15° 이내 |
| 보통 | 102° | 26° | 30° 이내 (시계 1칸) |

가만히 있을 때 "높음"이 나오는 경우: 수정 후 0%.

실제 기기의 GPS 노이즈는 모형과 다를 수 있으니, 정지 시험 기록을 `analyze_watch_log.py`로 분석해 `FLOOR_K`를 맞추세요.

### 실기기 정지 시험 (2026-10-23, 갤럭시 워치5 프로, 집 창가)

- **GPS**: 위성 약 11개, 정확도 중앙값 ±9.5m(닫힌 창문 안쪽). 위치가 수십 초에 ±15m씩 흘러,
  위치만 쓰면 가만히 있어도 가짜 흐름이 최대 1.4kn까지 "높음"으로 나왔다.
- **도플러 확인 추가**: 위치로 구한 속도가 GPS 칩의 도플러 속도보다 빠르면 속도를 낮추고 오차를 키움.
  30분 기록에서 '보통' 이상 잘못 표시 0.1%(약 2초). 위치와 도플러가 함께 속는 순간은 못 잡는다.
- **FLOOR_K**: 위치만으로 잰 노이즈는 모형의 1.6배(0.0281)였지만 창가 반사 탓일 수 있어 값은 그대로 둠.
  하늘이 트인 곳에서 다시 잴 것.
- **자기장**: 워치5 프로 기본 줄의 **자석 D-버클**이 있으면 270~320µT(정상의 6배), 빼면 40~47µT.
  자석 버클은 나침반을 망가뜨린다 → 자석 없는 줄 사용.
- **배터리**: 화면 계속 켜짐으로 시간당 13.6% → 100%에서 약 7.3시간.
